# UniFi | Payment Gateway

Integrate UniFi's stablecoin payment gateway into your existing product — whether it's a web app, mobile app, checkout flow, or backend service.

This release includes everything you need to get started:

- [**Docs**](http://docs.payunifi.com/payment-gateway/overview) — Integration guides, API references, and implementation details.
- [**Widget**](https://github.com/abhi3700/unifi-pay-widget) — A ready-to-use payment widget for embedding UniFi directly into your product checkout page.
- [**Example Project**](https://github.com/abhi3700/fliq-market) — A working reference implementation showing the complete integration flow.
