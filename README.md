# UniFi Releases

This directory contains release packages for the UniFi ecosystem.

Each package is organized independently and includes the files, documentation, and examples required to integrate or run that component.

## Documentation

For comprehensive UniFi documentation, integration guides, API references, and product documentation, visit [docs.payunifi.com](https://docs.payunifi.com).

## Releases

### CLI

UniFi command-line tooling for developers and operators.

→ [`cli/`](./cli)

### Falcon

Autonomous payment agent for self-custodial wallets, designed to execute wallet-native payment workflows using UniFi infrastructure.

→ [`falcon/`](./falcon)

### Payment Gateway

Stablecoin payment gateway for merchants and applications. Includes integration documentation, an embeddable payment widget, and a working example project.

→ [`payment-gateway/`](./payment-gateway)

### SDK

Developer SDKs for integrating UniFi functionality directly into applications and services.

→ [`sdk/`](./sdk)
